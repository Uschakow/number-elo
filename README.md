# Угадай число!
 **Игра угадай число, с системой Elo, Профилем с счетчиком побед/поражений и сохранения прогресса!**
---

## О проекте
Это мой первый проект на Python. Твоя задача угадать число от 1 до 3, победив ты получаешь случайное количество эло от 20 до 30, проиграв тоже самое но у тебя забирают столько же эло. Прогресс сохраняется тем самым ты можешь зайти позже.


## Как запустить?

1. Установи Python 3.10+
2. 1. Установи Python 3.10+
2. Склонируй репозиторий:
```bash
git clone https://github.com/Uschakow/number-elo.git
cd number-elo
```
3. Запусти:
```bash
python main.py
```
